梅花直播系统｜私密原版配置包

【换电脑按这个顺序】
1. 将整个压缩包解压到本机固态硬盘，例如 D:\MeihuaStudio；不要直接在压缩包里运行。
2. 双击“0-一键检测安装并启动.bat”。程序会先校验整包，再安装缺失的 OBS、VB-CABLE、TikFinity，然后导入当前画面、模型、声音和服务配置。
3. 如果刚安装 VB-CABLE，请重启 Windows，再次双击“0-一键检测安装并启动.bat”。
4. TikFinity 的平台登录状态受平台和 Windows 账号保护；如果提示未连接，只需登录并连接直播间一次。
5. OBS 使用导入的 MeihuaStudio 场景集合，唯一浏览器源为：http://127.0.0.1:5173/obs/source/meihua-stage，画布 1080x1920。
6. 以后日常使用双击“2-启动系统.bat”。
