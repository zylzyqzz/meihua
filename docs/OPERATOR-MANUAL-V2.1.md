# V2.1 投产操作手册

## 一次性配置

1. 在“接入健康”配置 TikFinity 地址。
2. 内容生成选择本地规则引擎，或配置公网 HTTPS 接口、模型和 API Key 后执行真实连接测试。
3. 语音选择 Windows 本地语音，或配置外部 TTS 的公网 HTTPS 接口、模型、声音与 API Key 后执行“生成并试听”。
4. 在“资格与队列”设置点赞门槛、免费排队分钟数、评论关键词、礼物名称与测算时长；累计、资格、连击终帧、插队和过期均由系统处理。
5. 在“画面工作台”设置文字、字体、颜色和底色，并只启用直播确实需要的 OBS 来源。
6. 人物优先使用透明/绿幕遮口动作素材；VTube Studio 仅作为可选阶段动作方案。

## OBS 添加规则

- 只添加画面来源，例如当前用户、卦象、队列、礼物提示、礼物榜、互动榜、状态、特效和免责声明。
- 字幕来源可选；关闭后不影响语音和测算流程。
- 不添加 `/obs/source/audio`。中控生产后端直接播放 WAV 到 Windows 默认输出设备，避免重复声音。
- OBS 负责位置、大小、裁剪、色度键和图层顺序；中控负责内容与联动状态。

## 开播流程

- **本地排练**：可不连接 TikFinity 或 OBS，用于验证排盘、内容、语音和画面样式。
- **正式开播**：必须通过数据库、已发布场景、TTS、TikFinity 合法事件、本机播放路径以及所有已启用 OBS 画面来源检查。VTube Studio 和预录人物回退仅产生警告，不是硬条件。

任务只有在后端确认 WAV 实际开始播放后才进入口播阶段，并以真实播放结束为完成依据。生成或播放失败会进入明确错误状态，不使用固定时长假装完成。

## Windows 生产启动

双击项目根目录的 `启动梅花直播中控.cmd`，或执行：

```powershell
pnpm start:production
```

启动器检查端口和数据目录，并由同一生产进程提供 API `3210`、OBS 来源 `5173` 与中文中控 `5200`。生产 API 使用每次启动生成的本机控制令牌；不要把 `data/runtime-control-token` 发给他人。日志按日期写入 `data/logs/`。

## 每场收播后

- 使用“正常收播”等待当前任务完成；紧急情况才使用“立即收播”。
- 本场榜单随场次冻结，下一场从零开始。
- 保存 OBS 录像、TikFinity 脱敏事件样本、场次报告和异常记录，作为验收证据。
