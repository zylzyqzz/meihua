# 0｜请先看这里

这是梅花直播系统完整一体包。中控、素材、GPT‑SoVITS声音克隆、离线语音识别、MuseTalk数字人、模型、Python、Node、FFmpeg、TikFinity和完整源码均已归档。

## 第一次使用只做四步

### 1｜检查环境并补齐依赖

双击 `1-环境检查与安装.bat`。

它会自动检查并补齐缺失环境，不再要求输入菜单数字。OBS静默安装；VB-CABLE会弹出官方安装页，确认管理员权限并点击一次 `Install Driver`，完成后窗口自动关闭。

它会检查：

- 一体包是否完整。
- NVIDIA显卡和驱动是否可用。
- OBS Studio是否安装。
- VB‑CABLE虚拟声卡是否安装。
- TikFinity是否存在。
- 声音克隆、数字人、模型和媒体工具是否齐全。
- 3210、5173、5200、9881、9898、9899端口是否被旧实例占用。

缺少OBS、VB‑CABLE或TikFinity时，按提示自动安装。安装VB‑CABLE后必须重启Windows一次。

### 2｜启动整套系统

双击 `2-启动系统.bat`。

启动窗口会立即消失。中控、声音克隆和数字人服务默认在后台运行，只显示中控页面与右下角托盘图标；运行日志统一保存在 `logs/`。

它会一次启动：TikFinity、GPT‑SoVITS、MuseTalk、梅花中控后台和OBS舞台。后台地址：

```text
http://127.0.0.1:5200/
```

### 3｜完成后台配置

打开 `3-操作攻略.md`，依次完成：

1. 在数字人中心上传声音并试听。
2. 上传人物视频并预览。
3. 选择人物和声音后启用。
4. 在画面工作台调整图层，点击“保存并发布到OBS”。
5. 在资格与队列设置评论、点赞和礼物规则。

### 4｜连接TikTok与OBS

- TikFinity登录和绑定：打开 `4-TikFinity图文攻略.md`。
- OBS只添加一个浏览器源：

```text
http://127.0.0.1:5173/obs/source/meihua-stage
宽 1080，高 1920，30fps
```

## 根目录说明

- `0-请先看这里.md`：当前说明。
- `1-环境检查与安装.bat`：检查并补齐运行环境。
- `2-启动系统.bat`：一键启动整套系统。
- `3-操作攻略.md`：中控、声音、数字人、画面和队列操作。
- `4-TikFinity图文攻略.md`：TikFinity下载、登录和直播间绑定。
- `5-源码/`：全链路干净源码和当前素材，不包含重复缓存。
- `6-真实状态说明.md`：哪些能力已实测、哪些必须在直播账号和RTX机器上现场验收。
- `app/`：中控运行文件和素材数据。
- `gptsovits/`：声音克隆完整运行环境及模型。
- `musetalk/`：数字人口型完整运行环境及模型。
- `desktop/`、`runtime/`：桌面程序与Node运行环境。
- `tikfinity/`：TikFinity桌面程序（若打包时已安装）。

普通使用者不要修改英文运行目录，只按0、1、2、3、4操作即可。
