# 当前实施状态

更新时间：2026-08-30

本文件只记录当前可验证状态。历史施工摘要见 `V2.2-V7.3-HISTORICAL-CHANGELOG.md`。

## 当前已实现

- 总控台、资格与队列、数据记录、画面工作台和数字人中心由同一中控管理。
- 工作台使用 1080×1920 场景模型；草稿只在本地编辑，点击“保存并发布到 OBS”后正式舞台才原子更新。
- 工作台和 `/obs/source/meihua-stage` 共用场景图层、模块和样式；OBS 正式地址保持唯一。
- 图层支持位置、尺寸、透明度、显示、锁定和排序；业务模块唯一，图片、视频和文字可重复添加。
- 图片、视频、3D 和系统素材由统一素材库管理；素材内容通过素材 ID 访问，删除前检查引用。
- 背景视频支持上传、兼容检测和 H.264/`yuv420p` 转码。
- Lux3D、罗盘和卦象已作为正式业务模块进入共享舞台。
- 礼物窗口只在直播画面显示礼物图标和自定义文案；礼物 ID、币值和时长只在后台管理。
- 数字人中心已收口为三步：声音克隆、数字人克隆、选择使用。
- 声音链路包含 FFmpeg、离线 Whisper、GPT-SoVITS V3 真实试听和持久化选择。
- 视频人物链路包含兼容转码、MuseTalk V1.5 预处理、人物预览和实际播报口型。
- 实际播报采用逐句预缓冲；MuseTalk 输出静音视频，Windows 唯一音频总线播放 WAV。
- 中控重启后已选择的人物、声音、MuseTalk 地址和 `READY` 状态保持。

## 仍需现场验收

- TikFinity 必须使用实际直播账号收到真实评论、点赞和礼物事件。
- OBS 必须在最终电脑上验证浏览器来源、VB-CABLE、NVENC 和 1080×1920 录制。
- RTX 3060 12GB 仍需完成 30 条连续测算和 2 小时运行，确认显存峰值、渲染丢帧、首句延迟和音画偏差。
- 示例或带水印人物不得直接投入商业直播，必须替换为已确认授权素材。
- 百度云端声音和数字人属于手动备用，未配置真实密钥时不标记为可用。

## 状态维护规则

- 测试数量只写最近一次完整命令结果。
- 文件上传成功不等于克隆成功；必须以真实试听、真实预处理和实际播报为证据。
- CPU 能运行不等于达到直播性能；性能结论只来自最终硬件实测。
- 外部账号、驱动或设备未验证时，不把系统标记为“完整投产”。
