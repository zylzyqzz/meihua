# V2.1 实现与验收状态

本表只记录有证据的状态。代码、Mock、页面存在或地址可访问均不等于真实直播验收完成。

| 功能 | 状态 | 证据 / 边界 |
|---|---|---|
| Windows TTS / 外部 TTS 生成 WAV | `AUTOMATED_VERIFIED` | Windows 实机生成、WAV 可播放性与时长测量测试通过；外部服务仍需逐个真实密钥验收 |
| 后端唯一音频播放路径 | `AUTOMATED_VERIFIED` | WAV 由生产后端直接播放到 Windows 默认输出；OBS 不再添加音频浏览器源 |
| 可选分句字幕 | `AUTOMATED_VERIFIED` | 使用实测 WAV 时长生成时间线；可在场景中关闭，不属于音频播放条件 |
| 数字人阶段动作 | `CODED` | 网页动作素材可用；VTube Studio 仅触发阶段热键，不发送口型参数，也不是开播硬条件 |
| 正式开播 / 本地排练隔离 | `AUTOMATED_VERIFIED` | 正式模式拒绝未验证 TikFinity、未就绪 TTS 和未连接的已启用 OBS 画面源 |
| TikFinity 顺序收件箱、去重与连击终帧 | `AUTOMATED_VERIFIED` | 无 ID payload 使用确定性指纹去重；真实直播字段仍需 `LIVE_VERIFIED` |
| 生产鉴权与本机来源约束 | `AUTOMATED_VERIFIED` | 3210 API 使用运行期令牌；5173/5200 注入令牌；生产环境关闭 Mock 与事件注入端点 |
| 外部服务目标与密钥绑定 | `AUTOMATED_VERIFIED` | 只允许公网 HTTPS；阻止本机/内网目标；服务来源变更会清除原验证与不匹配密钥 |
| SQLite 迁移、收件箱与备份 | `AUTOMATED_VERIFIED` | 迁移保留旧字段和 `/module/*` 兼容地址 |
| Windows 生产启动 | `AUTOMATED_VERIFIED` | 单一生产进程同时提供 3210、5173、5200，运行期令牌和日志已实启检查 |
| OBS 60 分钟录制 | `BLOCKED_EXTERNAL` | 需要 OBS 实际加载全部启用来源并保存录像和性能数据 |
| VTube Studio 真模型动作验收 | `BLOCKED_EXTERNAL` | 可选能力；需要正式 Live2D 模型和已配置动作热键 |
| TikFinity 实播评论、点赞、普通/连击礼物 | `BLOCKED_EXTERNAL` | 必须从真实直播间保存脱敏样本和录像后验收 |

最近代码验证：`pnpm typecheck`、`pnpm test`（71 项）与 `pnpm build` 均通过。生产进程已实启，但当前正式预检仍因 TikFinity、TTS 配置、OBS 实际来源连接和历史 MOCK 队列而失败；这是真实阻断，不得写成“已投产”。
