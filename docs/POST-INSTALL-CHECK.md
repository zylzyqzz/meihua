# 5｜安装完成后检查

安装完成后按下面顺序确认系统可以使用：

1. 打开 `http://127.0.0.1:5200/`，能看到梅花中控首页。
2. 在“数字人中心”确认声音和数字人服务显示为可用。
3. 在“画面工作台”点击“复制 OBS 地址”。
4. 打开 OBS，添加“浏览器”来源，填写复制的地址，宽度 `1080`，高度 `1920`。
5. 在 OBS 预览中确认直播背景、数字人和文字与工作台一致。
6. 先做一次测试测算，再开始正式直播。

## 出现问题时

- 重新双击根目录的 `2-启动系统.bat`。
- 仍然打不开时，运行 `安装工具\01-检查整包.bat`。
- 需要重新安装 OBS、VB-CABLE 或 TikFinity 时，运行 `安装工具\02-检查并安装环境.bat`。
- 日志在根目录的 `logs` 文件夹中；不要直接打开 `安装工具\内部` 里的 PowerShell 文件。
