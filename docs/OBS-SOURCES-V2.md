# OBS 来源清单与配置规范 V2

## 总则

OBS 负责坐标、缩放、裁剪、层级与最终 1080×1920 构图；中控只输出稳定浏览器来源。浏览器来源地址固定，不携带预览参数。

推荐默认：正式直播中只添加一条 `meihua-stage`（1080×1920，固定构图，见下表）。以下分层组合保留给高级自定义，旧地址不删除。

推荐图层从下到上（高级自定义）：

1. `background`
2. `avatar`
3. `hexagram`
4. `current-viewer`
5. `queue`、`gift-ranking`、`engagement-ranking`
6. `status`、`gift-alert`、`subtitles`、`disclaimer`
7. `effects`
8. `audio`（不可见，位置无意义）

## OBS 添加步骤

1. 在中控“简单设置”保存文字、字体和颜色；在“OBS 画面”保存人物与背景。
2. OBS 新建浏览器来源，粘贴对应正式地址。
3. 宽高使用上表或中控卡片显示值。
4. 不勾选页面关闭后刷新，避免场景切换时重新从头播放；是否关闭不可见来源由实际机器压测决定。
5. `audio` 只添加一次，并在 OBS 中启用通过 OBS 控制音频。
6. 人物和背景视频在页面端强制静音，禁止再捕获其音轨。
7. MP4 绿幕人物在 OBS 添加色度键；透明 WebM 不需要色度键。
8. 完成位置布局后锁定 OBS 来源，后续内容由中控自动更新。

## 实机验收记录项

- OBS 版本、Windows 版本、GPU、编码器。
- 各来源分辨率与缩放比例。
- 透明边缘、绿幕溢色和字体清晰度。
- 60 分钟连续运行的丢帧、渲染延迟和编码延迟。
- 一次完整评论、点赞、普通礼物、连击礼物、排队、测算和收尾录像。
- 关闭并重开来源后是否恢复当前 Cue，而非从头播放。
- 是否出现双重音频、空白来源或旧任务残留。

在完成录像和记录前，状态只能是 `BLOCKED_EXTERNAL` 或“待 OBS 实机验收”。
