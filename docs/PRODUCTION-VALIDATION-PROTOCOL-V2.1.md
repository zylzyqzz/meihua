# 梅花直播中控：真实投产验证协议 V2.1

## 状态口径

| 状态 | 允许说明 | 不允许说明 |
|---|---|---|
| `CODED` | 代码已实现 | 功能已验收 |
| `AUTOMATED_VERIFIED` | 自动化测试和构建通过 | 已完成 OBS 或 TikTok 实播联调 |
| `BROWSER_VERIFIED` | 浏览器真实交互通过 | OBS 录制通过 |
| `OBS_VERIFIED` | 已录制实际 OBS 画面并复核 | 已收到真实 TikTok 事件 |
| `LIVE_VERIFIED` | 已在真实 TikFinity Desktop 与直播间完成事件验收 | 外部软件和网络永不失败 |
| `BLOCKED_EXTERNAL` | 缺少 OBS、直播间、模型或外部密钥等实机证据 | 已投产 |

当前内部自动化已通过，但 OBS 60 分钟录像和 TikFinity 真实事件证据尚未完成，因此不能标记“已投产”。

## 版本检查

生产服务必须通过 `启动梅花直播中控.cmd` 或以下命令启动，不使用 Vite/tsx watch 作为正式进程：

```powershell
pnpm verify:offline
pnpm start:production
pnpm verify:readiness
```

`verify:offline` 必须退出 `0`。外部环境未连接时，`verify:readiness` 退出 `2` 并列出 TikFinity、TTS 或 OBS 阻断项是正确行为。

## A. TTS 与本机播放验收

1. Windows 本地语音：选择声音，生成至少一段中文和一段英文并试听。
2. 外部 TTS：必须配置公网 HTTPS 地址、模型、声音和 API Key，并通过真实 WAV 生成与试听；只保存地址不能标记 READY。
3. 确认声音只从 Windows 默认输出设备播放一次。
4. OBS 不添加 `/obs/source/audio`；该旧地址只为兼容保留，正式场景必须保持关闭。
5. 语音生成失败、文件不可播放或播放启动失败时，任务必须进入错误状态，不能按预估秒数假装完成。
6. 可选字幕应跟随实测 WAV 时间线；关闭字幕后，语音、排盘和队列仍须正常工作。

## C. TikFinity 真实事件验收

1. 启动 TikFinity Desktop，并确认 WebSocket 地址 `ws://127.0.0.1:21213/` 可访问。
2. 必须先收到字段合法的真实 `chat`、`gift` 或 `like`，连接才允许显示为已验证。
3. 依次产生一条有效评论、一次真实点赞、一个普通礼物、一个连击礼物及 `repeatEnd` 最终帧。
4. 核对收件箱只处理一次；资格、问题、队列、榜单和审计均绑定同一用户和场次。
5. 礼物先到时显示“已获权益、未提问”；同一用户随后评论问题才进入等待队列。已在队列时送礼应更新优先级和测算时长，但不抢断当前任务。
6. 点赞跨阈值只发一次限时资格；免费队列超时自动取消；礼物资格不按免费时限清除。
7. 断开 30 秒后恢复，不能清空场次、榜单和当前任务，也不能重复结算。
8. 保存脱敏 payload、解析版本、场次报告和 OBS 录像；缺少证据时只能标记“适配完成，待真实联调”。

## D. 完整链路

正式预检全部通过后，执行：

`真实礼物/点赞/评论 → 资格或待提问 → 问题绑定 → 排队 → 当前用户 → 起卦 → 结构化解读 → WAV 生成 → 后端实际播放 → 可选字幕/人物阶段动作 → 完成 → 下一位`

验收记录至少包含场次 ID、脱敏事件 ID、Cue 序号、WAV 路径与实测时长、录像时间码、榜单变化和异常处理结果。

## E. 可选人物验收

- 网页人物素材：验证待机、起卦、讲解、礼物感谢和结束动作按阶段切换，视频始终静音。
- VTube Studio：验证授权、模型名和阶段热键；OBS 直接抓取人物窗口。
- 不测试或承诺口型同步。建议使用遮口模型或自然循环动作。
- 人物不可用时不应伪装 READY，也不应阻断没有人物画面的核心测算直播。

## 失败处置

| 现象 | 立即动作 | 禁止做法 |
|---|---|---|
| TTS 或播放失败 | 暂停当前任务，显示具体错误并允许重试 | 用固定秒数假装已播完 |
| TikFinity 断线 | 暂停新事件，保留场次和当前画面，等待重连 | 清空队列或重复结算 |
| OBS 来源断开 | 重连后恢复当前快照；不需要的来源立即禁用 | 地址能打开就写“已连接” |
| 人物动作失败 | 回待机并记录告警 | 中断已开始语音或显示数字人 READY |
| 数据库写入失败 | 停止自动处理，保存日志后修复 | 静默继续处理直播事件 |
