# RTX 3060 12GB 部署与验收说明

更新时间：2026-08-30

## 推荐配置

- Windows 11
- i5-12400F 或同级处理器
- RTX 3060 12GB
- 32GB 内存
- 1TB NVMe
- OBS Studio 使用 NVENC，输出 1080×1920、30fps

本项目更重视显存容量，因此 3060 12GB 优先于 3060 Ti 8GB。程序只有一套；没有 CUDA 时会回退到 CPU，但 CPU 口型速度不作为直播性能基线。

## 安装

1. 安装 NVIDIA Studio Driver。
2. 安装 OBS Studio。
3. 安装 VB-Audio Virtual Cable。
4. 将完整 `MeihuaStudio` 目录解压到 NVMe。
5. 双击 `1-环境检查与安装.bat`，检查并补齐驱动、OBS、VB-CABLE、TikFinity及本地模型。
6. 双击 `2-启动系统.bat`。
7. 在数字人中心完成：克隆声音 → 克隆人物 → 选择使用。
8. 在画面工作台点击“保存并发布到 OBS”。
9. OBS 只添加 `http://127.0.0.1:5173/obs/source/meihua-stage`，尺寸 1080×1920、30fps。
10. Windows 输出设为 `CABLE Input`，OBS 只采集 `CABLE Output`，浏览器来源静音。

## 数字人运行限制

- 单人物、单路竖屏、30fps。
- GPT-SoVITS 同时只合成一条语音。
- MuseTalk 按句渲染并预缓冲，口型视频不含音轨。
- 不同时运行本地大语言模型、生成式人物视频或其他高显存任务。
- 新人物和新声音从下一条任务生效，当前任务不换人、不换声。

## 必须执行的实机验收

- 连续完成不少于 30 条测算。
- OBS 连续录制不少于 2 小时。
- 输出保持 1080×1920、30fps。
- OBS 渲染丢帧率低于 1%。
- 峰值显存低于 11GB，不能进入持续显存交换。
- 声音与口型偏差目标低于 100ms。
- 不出现双声、浏览器回声、人物黑屏、背景一秒循环或任务假完成。
- 分别断开 GPT-SoVITS、MuseTalk、音频设备和 OBS 舞台，确认任务保留失败原因且可重试。

## 当前边界

开发和真实功能链路已经在同一套程序上通过；RTX 3060 的上述长时间性能数据仍必须以最终电脑的实测结果填写，不能从 CPU 测试或模拟测试推断。
