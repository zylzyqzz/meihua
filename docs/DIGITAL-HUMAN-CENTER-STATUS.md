# 数字人中心当前真实状态

更新时间：2026-09-02

## 当前结论

声音克隆、视频数字人克隆、选择使用和实际播报已经组成一条真实链路，不再用“上传成功”“文件存在”冒充克隆成功。系统只有一套程序：同一安装包自动选择 CUDA 或 CPU；但 `COUNTRY_ACCENT` 目标口音和正式直播必须有 CUDA，CPU 只用于离线验证。

声音档现在明确拆分样音语言、目标播报语言、目标国家和实际口音模型。默认 `COUNTRY_ACCENT` 不允许静默回退到 GPT-SoVITS 原生音色；明确选择 `TIMBRE_ONLY` 才使用兼容模式。目标口音服务固定在 9899，模型或 CUDA 未就绪时会显示明确失败原因。

数字人中心固定为三步：

1. **声音克隆**：选择语言，上传 10–30 秒音频或视频，等待生成试听。
2. **数字人克隆**：上传正面单人物视频，等待预处理完成后直接预览人物。
3. **选择使用**：选择一个可用人物和一个可用声音，点击“保存并使用”。

克隆人物时不再强制生成一段无意义的试口型。实际播报时，后端才会根据真实测算内容逐句生成声音和口型。

## 已经具备的真实能力

### 声音克隆

- 支持 WAV、MP3、FLAC、M4A、MP4、MOV 和 WebM。
- 后端使用内置 FFmpeg 提取音轨并转换为单声道 PCM WAV。
- 内置离线 OpenAI Whisper Tiny；用户不再填写参考原文，系统自动识别样音内容。
- GPT-SoVITS V3 必须真正生成可播放的试听 WAV 后，声音才会标记为 `READY`。
- 新建声音档会先异步完成 ASR、目标口音生成和试听二次语言校验；目标语言、模型版本或 CUDA 不满足时不会进入直播 `READY`。
- 克隆结果保存在声音档案和音色包目录中，可试听、重新处理、选择和持久化。
- 已启用声音决定测算内容语言；选择英文声音时，后端生成英文解读并用该声音播报。

### 视频数字人

- 支持 MP4、MOV 和 WebM 人物视频。
- 上传后自动转为 H.264、`yuv420p`、30fps，并登记为受控素材。
- MuseTalk V1.5 完成人脸预处理和可复用缓存；预处理成功后人物即为 `READY`。
- 克隆后可以直接打开原人物视频预览。
- 实际播报时按句调用 MuseTalk 生成口型视频；人物源视频、声音、文案和速度共同参与缓存键。
- 人物和声音选择在中控重启后保持，不会再被旧的“必须先做口型试片”逻辑清空。

### 实际播报

- 测算内容按句切分，先生成当前句声音和口型，播放当前句时准备下一句。
- MuseTalk 输出严格为静音 MP4；声音只由 Windows 唯一音频总线播放。
- 舞台先预加载口型视频，再启动声音；浏览器和 OBS 不会重复播声音。
- 当前任务保存不可变的人物和声音快照，修改选择只影响下一条任务。
- 失败任务保留原因，可以重试，不会伪装成播放完成。

## 2026-08-30 真实验收证据

> 以下记录保留作历史证据；它验证的是旧的 `TIMBRE_ONLY`/CPU 链路，不代表当前默认的 `COUNTRY_ACCENT` 已完成 CUDA 直播验收。

- 16 秒英文样音上传后，离线 ASR 自动得到完整英文参考文本。
- GPT-SoVITS V3 使用该参考声音生成了 2.82 秒真实试听 WAV，声音状态进入 `READY`。
- 竖屏人物视频完成 MuseTalk CPU 预处理，人物状态进入 `READY`。
- 选择上述人物和声音后，手动播报 `Test.` 完成真实 TTS、口型渲染、舞台素材登记和 Windows 声音播放，任务状态为 `FINISHED`。
- 最终舞台素材经 FFprobe 检查：H.264、360×640、1.00 秒，只有视频流，没有 AAC 或其他音轨。
- 重启中控后复查：人物仍为 `READY`，人物和声音仍为当前选择，MuseTalk 地址仍为已保存地址。
- `pnpm typecheck` 通过。
- `pnpm test` 共 140 条测试通过。
- `pnpm build` 通过，Admin、Overlay 和 Orchestrator 均生成生产构建。

## 尚未完成的外部与性能验收

- 示例人物或带水印素材只能用于验证链路；正式直播必须换成确认授权、无水印的人物视频和声音样本。
- 当前已完成旧链路的 CPU 和真实服务功能验收；新的目标口音服务在 CUDA、OpenVoice V2 模型和目标机上仍需现场验收。
- TikFinity 是否收到真实直播事件、OBS 是否正确采集 VB-CABLE、国产云端备用是否可用，仍取决于现场账号、驱动、设备和密钥。
- CPU 可以完成部分旧链路的离线验证，但 `COUNTRY_ACCENT` 实时合成和正式直播不会把 CPU 标记为 READY。

## 不允许再出现的误报

- 只有样本文件，未生成试听 WAV：声音未完成。
- 只有人物原视频，MuseTalk 未完成预处理：人物未完成。
- 口型视频含音轨：唯一音频总线验收失败。
- 页面显示 `READY`，服务重启后选择丢失：持久化验收失败。
- 模拟接口测试通过：不能代替真实 GPT-SoVITS、MuseTalk、OBS 和 TikFinity 验收。
