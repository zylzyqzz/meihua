# TikTok 礼物目录与图标

## 当前范围

- 固定展示 48 个高频礼物，覆盖 1～5000 金币。
- 其中 13 个已由本机 TikFinity 真实事件捕获；其余来自 2026-08-27 当日平台目录。
- 每个礼物都保存真实 `giftId`、币值和 TikTok CDN 原始图标。
- 两张 24 格母图位于 `assets/generated/tiktok-gifts/`。
- 48 个切图位于 `apps/admin/public/gifts/`，由资格与队列页面直接使用。

## 准确性策略

1. `scripts/build-tiktok-gift-icons.py` 下载当天目录并逐项校验 ID 与币值。
2. 任意礼物缺失或币值变化时构建直接失败，不生成错误映射。
3. 直播中实际捕获的数据优先于参考目录；规则始终优先按 `giftId` 匹配，名称只做回退。
4. 地区或活动限定礼物只有在图标可验证时才进入固定目录。

本机曾捕获 `1045664 / 游戏玩家通行证水獭 / 100`，但当前公共目录未提供可核验图标，因此它仍会出现在“直播已捕获”列表中，但暂不绑定其他礼物的图片。

## 更新方法

```powershell
python scripts\build-tiktok-gift-icons.py
```

脚本成功时必须输出：

```text
verified=48 sheets=2 icons=48
```

礼物会因地区、活动和时间变化。正式实播中捕获到的新 ID 会自动进入系统目录；固定 48 项需要经过同样校验后才能替换。
