# 梅花直播系统安装器 v1.0.5

仓库当前为私有仓库。已登录本仓库的电脑可在 Windows PowerShell 中执行：

```powershell
git clone --depth 1 --single-branch --branch release/installer-v1.0.5 https://github.com/zylzyqzz/meihua.git "$env:USERPROFILE\Desktop\meihua-installer"
```

安装包位于 `Desktop\meihua-installer\release\installer\MeihuaInstaller-v1.0.5.zip`。完整解压后双击 `START-INSTALLER.cmd`，依次执行“检查环境”“一键补齐依赖”“开始安装”。中断后重新打开安装器并点击“继续安装”。
