# 梅花直播系统安装器 v1.0.5

在任意 Windows PowerShell 中执行，无需登录 GitHub：

```powershell
Invoke-WebRequest -UseBasicParsing "https://raw.githubusercontent.com/zylzyqzz/meihua/release/installer-v1.0.5/release/installer/MeihuaInstaller-v1.0.5.zip" -OutFile "$env:USERPROFILE\Desktop\MeihuaInstaller-v1.0.5.zip"
```

下载后完整解压，双击 `START-INSTALLER.cmd`，依次执行“检查环境”“一键补齐依赖”“开始安装”。中断后重新打开安装器并点击“继续安装”。
